# Demo checklist

1. Show the EcoCampus dashboard and the three summary cards.
2. Add an action with a category, CO₂ estimate, and optional detail.
3. Show that the summary and activity feed update.
4. Delete an entry and show the feed updates.
5. Explain the request flow: browser → Nginx → Express API → PostgreSQL.
6. Explain why PostgreSQL and the API are not exposed directly to the public internet.
7. Explain Terraform variables and run `terraform plan` before any cloud deployment.
